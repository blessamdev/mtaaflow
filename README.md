# MtaaFlow

Social-commerce storefront demo for Kenyan small businesses (React + Vite + Tailwind).

## Setup

```bash
npm install
npm run dev
```

Dev server: http://localhost:8443 (or `$PORT`).

## Build

```bash
npm run build
```

Output directory: `dist/`.

## Deploy

Static SPA. Deploy `dist/` to Vercel, Netlify, or Cloudflare Pages. Build command `npm run build`, output `dist`. No environment variables or backend required for demo. No secrets exposed.
